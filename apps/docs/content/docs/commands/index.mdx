agent-desktop has 60 commands in 11 groups. Every command prints one JSON envelope with `version`, `ok`, `command`, and either `data` or `error`; [JSON output](/desktop/json-output) defines it.

```bash
agent-desktop --help               # list every command
agent-desktop <command> --help     # flags and arguments for one command
agent-desktop skills get desktop   # the agent usage guide compiled into the binary
```

`--help` prints the flags of the binary you installed. Flags that apply to every command, such as `--headed`, `--session`, `--agent-id`, `--trace`, and the post-action `--wait-for` flags, are documented once in [Configuration](/desktop/configuration).
